# Timeline Notes

Timeline Notes is a Foundry VTT V14 module for campaign timeline notes in a dedicated sidebar tab.

In the sidebar, every note is sorted by year (most recent date first by default). If there is more than one note for a year, they are given their months as headings. If there is more than one for the same month, the days are split into headings. Anything but the year can be left blank in a note if it's supposed to refer to something with an unknown date or something more general. Notes can also be given an end-date if they represent a period of time, in which case it will be shown in both places on the timeline.

The GM can set up tags to help search or filter the notes across the timeline. They can also set up a different calendar to suit any world out there. The default is Gregorian, but feel free to make it whatever you want in the settings.

The timeline sidebar shows a colour indicator on the left side of each note that corresponds to the colour the player chose to represent them. The right side has the colours of each tag applied to the the note.

Notes can also be set to be either private (in which case there's no sign of them for other players), viewable by anyone, or even editable by anyone. The last one can be very useful for players who help each other keep track of plot-points. The GM can always see and edit all notes.
